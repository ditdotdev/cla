# Dit Contributor License Agreement

This repository is the canonical home of the Dit Contributor License Agreement
and the record of everyone who has signed it.

- **[CLA.md](CLA.md)** — the Individual Contributor License Agreement text.
- **[signatures/](signatures/)** — the machine-maintained signature record.
  `signatures/version1/cla.json` is written by the
  [CLA Assistant GitHub Action](https://github.com/contributor-assistant/github-action)
  whenever a contributor signs on a pull request in any Dit repository. Do not
  edit it by hand; the git history of this file is the audit trail.

## How signing works

When you open your first pull request to a Dit repository, the CLA Assistant
bot comments with a link to [CLA.md](CLA.md). To sign, reply on the pull
request with:

> I have read the CLA Document and I hereby sign the CLA

Your signature is recorded here once, and covers all your future
contributions to every Dit repository.

## Versioning

If the CLA text materially changes, a new `signatures/versionN/` directory is
created and contributors are asked to sign the new version on their next pull
request. Existing signature files are never modified or removed.
